# 《元幻》GitHub 云端打包 APK 超详细教程（零基础版）

> 适用人群：电脑上没有、也不想安装 Android SDK。
> 原理：把工程上传到 GitHub（免费代码托管网站），让 GitHub 的服务器自动帮您编译出 APK。
> 全程只需浏览器操作，不需要安装任何软件，不需要懂 git 命令。

---

## 第 0 步：准备东西（2 分钟）

- 一个邮箱（用来注册 GitHub 账号）
- 本项目的 `cordova` 文件夹（里面应该有：config.xml、package.json、build.sh、www、res、.github、.gitignore、打包说明.md）

⚠️ **检查 `.github` 文件夹是否存在**：它是隐藏文件夹。Windows 上打开「文件资源管理器 → 查看 → 勾选"隐藏的项目"」就能看到；如果没有它，云端打包不会工作。

---

## 第 1 步：注册 GitHub 账号（约 3 分钟）

1. 浏览器打开 **https://github.com**（如果打不开，多试几次或换个网络，GitHub 在国内一般可以访问，偶尔不稳定）
2. 点右上角 **Sign up**（注册）
3. 依次填写：邮箱 → 密码 → 用户名（英文，随便起）→ 按提示完成人机验证
4. 到邮箱里复制验证码，填进去，完成注册

---

## 第 2 步：新建一个仓库（约 1 分钟）

1. 登录后，点页面**右上角的「+」号** → 选 **New repository**（新建仓库）
2. 填写：
   - **Repository name（仓库名）**：填 `yuanhuan`（或任意英文名）
   - 选 **Public**（公开，免费的云端构建时长足够用；选 Private 私有也行，每月有 2000 分钟免费额度）
   - ✅ 勾选 **Add a README file**（方便后面操作）
3. 点页面底部绿色按钮 **Create repository**

---

## 第 3 步：上传游戏工程文件（约 3 分钟）

这一步是把 `cordova` 文件夹**里面的内容**传到仓库（注意：不是上传 cordova 文件夹本身，而是它里面的所有文件）。

1. 进入刚建好的仓库页面，点中间偏右的 **Add file** 按钮 → 选 **Upload files**（上传文件）
2. 打开电脑上的 `cordova` 文件夹，**全选里面的所有内容**（包括 `.github` 隐藏文件夹！），直接**拖拽**到网页中间的虚线框里
   - 拖拽后网页会显示一堆文件正在上传，等进度条全部完成
   - 上传完成后，文件列表里应该能看到：`config.xml`、`package.json`、`www` 文件夹、`res` 文件夹、`.github` 文件夹等
3. 拉到底部，直接点绿色按钮 **Commit changes**（提交），弹窗里再点一次 **Commit changes**

✅ **自查**：回到仓库首页，确认能看到 `.github` 文件夹和 `www` 文件夹。如果看不到 `.github`，说明隐藏文件夹没传上，重新单独拖一次 `.github` 文件夹。

> 💡 **如果不小心把 cordova 文件夹整个套着传上去了**（仓库里看到 `yuanhuan/cordova/config.xml` 这样的两层结构）：**不用删除重来**，工作流已自动兼容这种结构，只需按上面的方法把 `.github` 文件夹补传到仓库首页（根目录）即可。

### ⚠️ `.github` 文件夹传不上去怎么办（浏览器会过滤隐藏文件夹）

Windows/Mac 的浏览器文件选择器默认**不显示以点开头的隐藏文件夹**，拖拽也常被拦。改用「网页直接新建文件」，100% 成功：

1. 仓库首页点 **Add file** → **Create new file**（新建文件，不是 Upload files）
2. 页面顶部文件名输入框（提示 `Name your file...`）里**整串粘贴**：
   ```
   .github/workflows/build-android.yml
   ```
   （斜杠会自动创建 `.github` 与 `workflows` 两层文件夹）
3. 下方大编辑框里粘贴完整的工作流配置（见本文件末尾「附：工作流配置全文」）
4. 拉到底部点绿色 **Commit changes** → 弹窗再点 **Commit changes**
5. 回到 **Actions** 标签页刷新，左侧就会出现 `Build 元幻 Android APK`

## 附：工作流配置全文（复制粘贴用）

```yaml
name: Build 元幻 Android APK

on:
  workflow_dispatch:
  push:
    branches: [main, master]

jobs:
  build:
    runs-on: ubuntu-latest
    timeout-minutes: 30
    steps:
      - name: 检出代码
        uses: actions/checkout@v4

      - name: 安装 JDK 17
        uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: '17'

      - name: 安装 Node.js
        uses: actions/setup-node@v4
        with:
          node-version: '20'

      - name: 准备 Android SDK（用服务器预装版，不再调用 setup-android）
        run: |
          export ANDROID_HOME="${ANDROID_HOME:-/usr/local/lib/android/sdk}"
          echo "ANDROID_HOME=$ANDROID_HOME" >> "$GITHUB_ENV"
          echo "ANDROID_SDK_ROOT=$ANDROID_HOME" >> "$GITHUB_ENV"
          echo "$ANDROID_HOME/platform-tools" >> "$GITHUB_PATH"
          echo "$ANDROID_HOME/cmdline-tools/latest/bin" >> "$GITHUB_PATH"
          echo "SDK 目录内容："
          ls "$ANDROID_HOME" || true
          SDKMANAGER="$(find "$ANDROID_HOME" -name sdkmanager -type f 2>/dev/null | head -1)"
          echo "sdkmanager 路径: $SDKMANAGER"
          yes | "$SDKMANAGER" --licenses > /dev/null 2>&1 || true
          "$SDKMANAGER" "platform-tools" "platforms;android-34" "build-tools;34.0.0" > /dev/null 2>&1 || true
          echo "已安装的 platforms："
          ls "$ANDROID_HOME/platforms" || true

      - name: 安装 Cordova CLI
        run: npm install -g cordova

      - name: 定位工程目录并构建 APK
        run: |
          if [ -d cordova ] && [ -f cordova/config.xml ]; then cd cordova; fi
          echo "构建工作目录: $(pwd)"
          ls -la
          cordova platform add android
          cordova build android

      - name: 上传 APK 产物
        uses: actions/upload-artifact@v4
        with:
          name: 元幻-debug-apk
          path: '**/app/build/outputs/apk/debug/app-debug.apk'
          retention-days: 30
```

## 第 4 步：启动云端构建（约 1 分钟操作 + 等待 5~10 分钟）

1. 在仓库页面顶部，点 **Actions** 标签页（在 Code / Issues / Pull requests 旁边）
2. **第一次**进 Actions 会看到一个绿色横幅，点 **"I understand my workflows, go ahead and enable them"**（启用工作流）
3. 页面左侧栏会列出工作流，点 **「Build 元幻 Android APK」**
4. 页面右侧出现一个 **Run workflow ▾** 灰色按钮 → 点它 → 弹出小面板 → 点绿色 **Run workflow** 按钮
5. 刷新一下页面（等 5 秒左右），列表里会出现一条新的构建记录，前面有🟡黄色圆点在转动 = **正在构建中**

---

## 第 5 步：下载 APK（构建完成后）

1. 等 5~10 分钟，🟡变成 ✅绿色对勾 = 构建成功（❌红色叉 = 失败，见下方「失败了怎么办」）
2. 点击那条✅构建记录进入详情页
3. 拉到**页面最底部**，找到 **Artifacts**（构建产物）区域
4. 点 **元幻-debug-apk** 下载，得到一个 zip 压缩包
5. 解压 zip，里面就是 **app-debug.apk**

---

## 第 6 步：传到手机安装

任选一种方式把 `app-debug.apk` 传到安卓手机：
- 微信「文件传输助手」发送文件 → 手机微信里点开下载 → 点安装
- 数据线连电脑直接拷贝
- QQ 发送文件

手机上安装时如果提示「未知来源应用」，按提示允许一次即可。装完图标是游戏 Logo，名字是「元幻」。

---

## 失败了怎么办（❌红色叉）

1. 点进失败的构建记录 → 点左侧 `build` → 右边会展开每一步的日志
2. 找到**红色报错的那一步**，把红色文字截图或复制下来发给我，我帮您排查
3. 最常见的原因：
   - `.github` 文件夹没上传成功 → 回第 3 步重传
   - GitHub 服务器下载 Gradle 超时 → 不用改任何东西，直接回到 Actions 页重新 **Run workflow** 再跑一次即可

## 以后游戏更新了怎么重新打包（每次版本更新都走这 3 步）

游戏的所有代码、模型、贴图、Logo **全部内嵌在 `www/index.html` 这一个文件里**，所以每次更新只需要替换这一个文件，其它文件（config.xml、package.json、.github 工作流）都不用再动。

### 第 1 步：删掉仓库里的旧 index.html

1. 进仓库，依次点开 `www` 文件夹 → 点 `index.html` 这个文件名
2. 右上角 **⋯（三个点）** → **Delete file**
3. 底部点绿色 **Commit changes** → 弹窗再点一次 **Commit changes**

> 如果您的仓库是 `cordova/www/index.html` 两层结构，就先点开 `cordova` 文件夹再点 `www`。

### 第 2 步：上传新的 index.html

1. 回到仓库首页（或 `www` 文件夹页面），点 **Add file → Upload files**
2. 把电脑上新的 `元幻-安卓单文件版.html`（或 `cordova/www/index.html`，约 4MB）**拖进虚线框**
3. 上传完，如果是首页上传的文件，需要在文件名框里手动改成 `www/index.html`（保证路径正确）
4. 底部点绿色 **Commit changes**

⚠️ **两个不要做的事**：
- **不要用铅笔（Edit）打开改内容** —— 新版本 4MB，网页编辑器会直接卡死
- **不要用 Create new file 粘贴内容** —— 4MB 文本粘贴不进去

### 第 3 步：重新构建

**Actions → Build 元幻 Android APK → Run workflow ▾ → Run workflow**，等 5~10 分钟 → 下载 Artifacts 里的 `元幻-debug-apk`。

> 每次构建产物保留 30 天，记得及时下载。

---

## ⚠️ 安装新版本前：必须先卸载手机上的旧版

云端每次构建都会生成**新的调试签名**，和您上次装的那个 APK 签名不一样。Android 不允许不同签名的同名应用覆盖安装，直接装会提示：

- 「应用未安装」
- 「与已安装的应用签名不一致」
- 或装完打不开 / 数据异常

**正确做法**：

1. 手机上**长按「元幻」图标 → 卸载**（或 设置 → 应用管理 → 元幻 → 卸载）
2. 再把新的 `app-debug.apk` 传到手机安装

> 代价：卸载会清掉本地存档（游戏进度）。存档目前存在手机本地，还没做云存档，介意的话先别急着更新，或者接受从头开始。
