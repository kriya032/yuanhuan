# 《元幻》GitHub 云端打包 APK 超详细教程（零基础版）

> 适用人群：电脑上没有、也不想安装 Android SDK。
> 原理：把工程上传到 GitHub（免费代码托管网站），让 GitHub 的服务器自动帮您编译出 APK。
> 全程只需浏览器操作，不需要安装任何软件，不需要懂 git 命令。

---

## 第 0 步：准备东西（2 分钟）

- 一个邮箱（用来注册 GitHub 账号）
- 本项目的 `cordova` 文件夹（里面应该有：config.xml、package.json、build.sh、www、res、.github、.gitignore、打包说明.md）

⚠️ **检查 `.github` 文件夹是否存在**：它是隐藏文件夹。Windows 上打开「文件资源管理器 → 查看 → 勾选"隐藏的项目"」就能看到；如果没有它，云端打包不会工作。

---

## 第 1 步：注册 GitHub 账号（约 3 分钟）

1. 浏览器打开 **https://github.com**（如果打不开，多试几次或换个网络，GitHub 在国内一般可以访问，偶尔不稳定）
2. 点右上角 **Sign up**（注册）
3. 依次填写：邮箱 → 密码 → 用户名（英文，随便起）→ 按提示完成人机验证
4. 到邮箱里复制验证码，填进去，完成注册

---

## 第 2 步：新建一个仓库（约 1 分钟）

1. 登录后，点页面**右上角的「+」号** → 选 **New repository**（新建仓库）
2. 填写：
   - **Repository name（仓库名）**：填 `yuanhuan`（或任意英文名）
   - 选 **Public**（公开，免费的云端构建时长足够用；选 Private 私有也行，每月有 2000 分钟免费额度）
   - ✅ 勾选 **Add a README file**（方便后面操作）
3. 点页面底部绿色按钮 **Create repository**

---

## 第 3 步：上传游戏工程文件（约 3 分钟）

这一步是把 `cordova` 文件夹**里面的内容**传到仓库（注意：不是上传 cordova 文件夹本身，而是它里面的所有文件）。

1. 进入刚建好的仓库页面，点中间偏右的 **Add file** 按钮 → 选 **Upload files**（上传文件）
2. 打开电脑上的 `cordova` 文件夹，**全选里面的所有内容**（包括 `.github` 隐藏文件夹！），直接**拖拽**到网页中间的虚线框里
   - 拖拽后网页会显示一堆文件正在上传，等进度条全部完成
   - 上传完成后，文件列表里应该能看到：`config.xml`、`package.json`、`www` 文件夹、`res` 文件夹、`.github` 文件夹等
3. 拉到底部，直接点绿色按钮 **Commit changes**（提交），弹窗里再点一次 **Commit changes**

✅ **自查**：回到仓库首页，确认能看到 `.github` 文件夹和 `www` 文件夹。如果看不到 `.github`，说明隐藏文件夹没传上，重新单独拖一次 `.github` 文件夹。

---

## 第 4 步：启动云端构建（约 1 分钟操作 + 等待 5~10 分钟）

1. 在仓库页面顶部，点 **Actions** 标签页（在 Code / Issues / Pull requests 旁边）
2. **第一次**进 Actions 会看到一个绿色横幅，点 **"I understand my workflows, go ahead and enable them"**（启用工作流）
3. 页面左侧栏会列出工作流，点 **「Build 元幻 Android APK」**
4. 页面右侧出现一个 **Run workflow ▾** 灰色按钮 → 点它 → 弹出小面板 → 点绿色 **Run workflow** 按钮
5. 刷新一下页面（等 5 秒左右），列表里会出现一条新的构建记录，前面有🟡黄色圆点在转动 = **正在构建中**

---

## 第 5 步：下载 APK（构建完成后）

1. 等 5~10 分钟，🟡变成 ✅绿色对勾 = 构建成功（❌红色叉 = 失败，见下方「失败了怎么办」）
2. 点击那条✅构建记录进入详情页
3. 拉到**页面最底部**，找到 **Artifacts**（构建产物）区域
4. 点 **元幻-debug-apk** 下载，得到一个 zip 压缩包
5. 解压 zip，里面就是 **app-debug.apk**

---

## 第 6 步：传到手机安装

任选一种方式把 `app-debug.apk` 传到安卓手机：
- 微信「文件传输助手」发送文件 → 手机微信里点开下载 → 点安装
- 数据线连电脑直接拷贝
- QQ 发送文件

手机上安装时如果提示「未知来源应用」，按提示允许一次即可。装完图标是游戏 Logo，名字是「元幻」。

---

## 失败了怎么办（❌红色叉）

1. 点进失败的构建记录 → 点左侧 `build` → 右边会展开每一步的日志
2. 找到**红色报错的那一步**，把红色文字截图或复制下来发给我，我帮您排查
3. 最常见的原因：
   - `.github` 文件夹没上传成功 → 回第 3 步重传
   - GitHub 服务器下载 Gradle 超时 → 不用改任何东西，直接回到 Actions 页重新 **Run workflow** 再跑一次即可

---

## 以后游戏更新了怎么重新打包

1. 在仓库里找到 `www/index.html` → 点文件名进入 → 右上角铅笔图标（Edit）旁选 **⋯** → **Delete file** 删除旧的
2. 或者更简单：仓库首页 **Add file → Upload files**，把新的 `www/index.html` 拖进去（会提示覆盖，提交即可）
3. 回到 **Actions → Build 元幻 Android APK → Run workflow** 再跑一次 → 下载新 APK

> 每次构建产物保留 30 天，记得及时下载。
