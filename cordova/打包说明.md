# 《元幻》安卓 APK 打包说明（Cordova 工程）

本目录是可直接构建安卓 APK 的 Cordova 工程。游戏全部逻辑与 three.js 引擎已内嵌在
`www/index.html`（约 970KB，单文件、完全离线），无需额外网络资源。

## 不想装 Android SDK？三条替代路线

| 方案 | 是否需要本地 SDK | 难度 | 说明 |
|------|----------------|------|------|
| **① GitHub Actions 云端构建（推荐）** | ❌ 不需要 | ⭐⭐ | 工程已内置工作流 `.github/workflows/build-android.yml`，SDK/JDK/Node 全在云端装好免费构建 |
| **② 在线 APP 封装服务** | ❌ 不需要 | ⭐ | 上传 `www/index.html` 一键生成 APK（WebIntoApp / Website 2 APK Builder 等），本质 WebView 壳，几分钟出包但功能受限（无原生图标/推送等定制） |
| **③ 本地安装 Android SDK** | ✅ 需要 | ⭐⭐⭐ | 完整控制，见下方「环境要求」 |

### ① GitHub Actions 云端构建步骤（免费，无需任何本地安装）

> 📖 **零基础详细图文教程请看同目录《云端打包教程.md》**（每一步点哪个按钮都写清楚了）

1. 把本 `cordova` 文件夹内容作为仓库根目录上传到 GitHub（公开仓库免费）
   - 注意保留 `.github/` 文件夹与 `www/index.html`
2. 打开仓库页面 → **Actions** → 左侧选择 `Build 元幻 Android APK`
3. 点击 **Run workflow** → 选择分支运行
4. 等待约 5–10 分钟，构建完成后在页面下方的 **Artifacts** 区下载 `元幻-debug-apk`（解压得到 APK，传到手机安装）

> 提示：云构建用的文件和本地完全一致，修改游戏后重新上传/推送再运行一次即可。

## 工程结构

```
cordova/
├── config.xml      # Cordova 应用配置（应用名「元幻」、全屏、深色背景）
├── package.json    # 依赖与构建脚本
├── build.sh        # 本地一键构建脚本（Linux/macOS）
├── .github/
│   └── workflows/
│       └── build-android.yml   # GitHub 云端构建（无需本地 Android SDK）
├── res/
│   └── icon.jpg    # 安卓 APP 图标（游戏 Logo）
└── www/
    └── index.html  # 游戏本体（引擎内嵌，离线可玩）
```

## 环境要求（打包用的电脑，任意一台普通 Windows/macOS 即可）

| 工具 | 版本要求 | 安装方式 |
|------|---------|---------|
| Node.js | ≥ 16 | https://nodejs.org 下载安装 |
| Java JDK | 17 | `winget install Microsoft.OpenJDK.17` 或 https://learn.microsoft.com/java/openjdk/download 下载 |
| Android SDK | API 34 | 见下方「Android SDK 安装指引」 |
| Gradle | 无需手装 | Cordova 自动下载 |

### Android SDK 安装指引（二选一）

**方式 A：Android Studio 一体安装（最省心，推荐新手）**

1. 下载 Android Studio：
   - 国际地址：https://developer.android.com/studio
   - 国内可访问：https://developer.android.google.cn/studio
2. 安装时一路默认（会自动装好 Android SDK、platform-tools、Gradle 所需组件）
3. 首次启动 → 更多设置里确认 SDK Platform 34 已安装：
   `Settings → Languages & Frameworks → Android SDK → SDK Platforms 勾选 Android 14 (API 34)`

**方式 B：仅命令行工具（体积小，不装 IDE）**

1. 打开 https://developer.android.google.cn/studio 页面，滚动到最底部
   **「Command line tools only」**区块，下载对应系统的 zip（Windows 版约 150MB）
2. 解压到固定目录（例如 `C:\android-sdk\cmdline-tools\latest\`，注意保留 latest 这层）
3. 用其中的 `sdkmanager` 安装所需组件并接受许可：

```bash
cd C:\android-sdk\cmdline-tools\latest\bin
sdkmanager "platform-tools" "platforms;android-34" "build-tools;34.0.0"
sdkmanager --licenses     # 全部输入 y 接受
```

4. 配置环境变量（Windows 在「系统属性→环境变量」）：

```
ANDROID_HOME = C:\android-sdk
ANDROID_SDK_ROOT = C:\android-sdk
Path 追加: %ANDROID_HOME%\platform-tools;%ANDROID_HOME%\cmdline-tools\latest\bin
```

5. 国内网络慢/失败时可用腾讯镜像下载 SDK 组件：
   https://mirrors.cloud.tencent.com/AndroidSDK/

### 环境自检（打包前运行）

```bash
java -version     # 应显示 17.x（cordova-android 13 要求 JDK 17）
node -v           # ≥ 16
adb version       # 能输出版本号说明 Android SDK 配置成功
```

鸿蒙/无 Java 环境的设备（如当前这台）无法本地编译，请把整个 `cordova` 文件夹
拷贝到任意装有上述环境的电脑上进行打包。

## 打包步骤

### 方式一：命令行（推荐）

```bash
cd cordova

# 1. 安装 Cordova CLI
npm install -g cordova

# 2. 添加安卓平台（首次）
cordova platform add android

# 3. 构建 APK
cordova build android
```

构建成功后，APK 位于：
```
platforms/android/app/build/outputs/apk/debug/app-debug.apk
```

把 `app-debug.apk` 传到安卓手机，点开即可安装游玩（需允许「安装未知来源应用」）。

### 方式二：一键脚本

```bash
bash build.sh
```

### 发布正式版（可选）

```bash
# 生成未签名 release APK
cordova build android --release

# 用自己的签名密钥签名（示例）
keytool -genkey -v -keystore yuanhuan.keystore -alias yuanhuan -keyalg RSA -validity 10000
apksigner sign --ks yuanhuan.keystore platforms/android/app/build/outputs/apk/release/app-release-unsigned.apk
```

## 修改游戏后重新打包

游戏源码在上级目录 `game/index.html`（引用同目录 `three.min.js` 与 `assets/logo.jpg`）。
修改源码后，在本目录重新执行内嵌合并（引擎 + Logo base64）并复制到 www：

```bash
node -e "
const fs=require('fs');
const three=fs.readFileSync('../game/three.min.js','utf8');
const logo='data:image/jpeg;base64,'+fs.readFileSync('../game/assets/logo.jpg').toString('base64');
let html=fs.readFileSync('../game/index.html','utf8');
// 注意：必须用函数替换，否则 three.min.js 中的 \$& 会被当作替换模式导致文件损坏
html=html.replace('<script src=\"./three.min.js\"></script>', function(){ return '<script>'+three+'</scr'+'ipt>'; });
html=html.replace('var LOGO_DATA = 0;', function(){ return 'var LOGO_DATA = '+JSON.stringify(logo)+';'; });
fs.writeFileSync('www/index.html',html);
console.log('www updated');
"
cordova build android
```

## 常见问题

- **白屏**：旧版安卓 WebView 不支持 WebGL。可在 `config.xml` 的 android 平台加入
  `<preference name="AndroidLegacy" value="false" />` 并安装 Crosswalk（已停维护），
  或要求 Android 8+ 设备（现代 WebView 均支持 WebGL，覆盖 95%+ 设备）。
- **构建卡在下载 Gradle**：网络问题，可手动设置镜像
  `gradle.properties` 中加 `systemProp.http.proxyHost=...`，或使用国内镜像源。
- **游戏进度**：存于 WebView 的 localStorage，卸载 APP 会清档，属预期行为。
